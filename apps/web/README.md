# MIZAN CORE Web

Arabic-first Next.js interface for the MIZAN CORE recovery workspace.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current limits

This is a UI scaffold only. It does not connect to the governance engine, authenticate users, make governance decisions, or call Supabase. The UI explicitly labels the API as not connected. Do not treat the preview as a production control plane.

# Moroco-atlas-

Morocco Atlas is a modern single-page showcase that presents the beauty, geography, culture, and major destinations of Morocco.

## Features
- Modern landing page with responsive layout
- Interactive region explorer
- Key Morocco highlights and city cards
- Lightweight static app with no dependencies

## Run locally
Open `index.html` directly in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

# Morocco Atlas

Morocco Atlas is a complete travel and cultural showcase app for Morocco. It includes a modern landing page, destination cards, detailed city views, an advanced search, itinerary planner, and booking form.

## Features
- Arabic RTL interface
- Interactive Morocco map
- Filterable destination explorer
- Search system by city or description
- Detailed panel for each city
- Itinerary generator
- Experience cards and booking form
- Responsive design for desktop and mobile

## Run locally
Open `index.html` directly in a browser, or serve the project with a local static server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project structure
- `index.html` — app layout and sections
- `styles.css` — design system and responsive styling
- `script.js` — data-driven interaction logic, filters, map selection, booking form, and itinerary planner

## Notes
This is a lightweight front-end app built with plain HTML/CSS/JavaScript, so it works instantly without a backend or install step.
